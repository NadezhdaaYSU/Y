Each mutant changes one thing in `src/ptx_emitter.rs` (`emit_drift_stop`,
`drift_loop_defers` and the `for` lowering), then the compiler is built and
run against tests/zero_drift_stop_point.rs, python/y_lang/tests/
test_drift_stop_point.py and tests/zero_drift_f32_conversion.rs. The source
was written back and rebuilt after each run, and compared with the original.

31 mutants: 30 fail a test; 1 is equivalent.

- R10 (an inner loop's bounds not checked) is equivalent: a loop's bounds
  can only be a name or a literal (`parse_loop_bound_expr`; even `(N)` does
  not parse), so nothing with an effect can reach that check. It is kept in
  case the grammar widens.
- R4 and R5 first deleted `return` and `while` from the list of refused
  statements, and the build failed: the `match` lists every statement kind,
  so a removed one does not compile. R4b and R5b accept them instead.
- R5b survived the first run: the only test `while` held the loop's sole
  term, so no accumulation was seen and nothing deferred either way. The
  test now also has a `while` beside a term, and kills it.
- S3 (the flag not cleared) gives the right answers on the GPU and the
  interpreter, where the uncleared predicate read as false; only the
  emitted-shape test catches it.
